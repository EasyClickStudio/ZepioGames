# ZepioGames

Official web repository for **ZepioGames** — an indie web gaming portal supporting HTML5 games, Microsoft MakeCode Arcade, Scratch (via TurboWarp), and web-based engines.

---

## Architecture

- **Frontend:** Single-file static web application (`index.html`). No build pipelines or bundlers required.
- **Database:** Flat JSON database (`games.json`). Update your game catalog without altering application code.
- **Deployment:** GitHub Pages static hosting with zero backend maintenance and automated deployments on every commit.
